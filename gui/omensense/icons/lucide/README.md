# Lucide icons

Section, mode and action icons come from [Lucide](https://lucide.dev), used
under the ISC licence in `LICENSE`. They ship with `stroke="currentColor"`;
`theme.icon()` substitutes a token colour at load time rather than keeping a
coloured copy of every icon per state.

The seven animation glyphs (Colour cycle, Rainbow wave, Breathing, Heartbeat,
Chase, Fire, Aurora) and the layout swatches are **not** from this set. They
are drawn in `widgets.py` from what each effect does.
